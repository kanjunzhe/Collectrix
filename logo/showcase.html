八个方向

8 variants · hover to preview
01纯几何

Tile Play 矩阵方砖

一块圆角方砖就是应用图标本身，播放三角用负空间直接切出。方块＝“库”这一块地基，三角＝内容。最耐缩小，16px 仍可辨认，适合做桌面/安卓图标与 favicon。

02点阵

Dot Play 点阵浮现

点阵网格代表一条条收藏，九个实心格子拼出播放三角，四角压到 11% 灰做“矩阵”暗示。说的是收藏的本质：从一堆条目里一眼看出内容。

03线系统

Converge 多源合流

五条来自左侧的来源（B 站 / YouTube / 抖音 / GitHub / 博客）收束成右侧一个实心节点。这就是产品最核心的动作：多源导入，落到同一个本地库。

04字母

C Play C 字播放

粗弧 C 取自 Collectrix 首字母，缺口刚好被播放三角填住——字形与功能一次说完。最适合放在字标左侧当符号位，也适合做圆形社交头像。

05层叠

Card Stack 一叠收藏

三张错位的圆角卡片，像已经入库、可以逐张翻阅的收藏，最上面一张切出播放。强调“本地、实体、属于你”的那一面，和云盘类产品拉开距离。

06网络

Node Graph 知识网络

四个卫星节点（分类 / 标签 / 主题 / 记事本）连向中心枢纽，枢纽里藏着一枚播放键。对应 README 后半段的“知识管理”：单个视频会连成网。

07条状

Spine Library 书架书脊

四根高低不一的“书脊”既像书架，也像视频时长条；右侧一枚播放三角收尾。疏密有节奏、体量扎实，适合做启动页或大尺寸打印头像。

08取景框

Corner Frame 四角取景

四角取景框把内容框住，中心留一枚播放键——“收藏＝取景归档”。最克制的一版，线条只有一种粗细逻辑，适合与等宽字体搭配的极客气质。
